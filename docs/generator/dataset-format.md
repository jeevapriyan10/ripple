# Ripple Dataset Format Specification

This document specifies the on-disk storage layout, serialization rules, and manifest schema for datasets generated by `ripple.generator`.

---

## Directory Structure

A generated dataset resides in a subdirectory named after the dataset under the configured data directory (e.g. `./data/datasets/<name>`):

```
datasets/<dataset_name>/
├── events.jsonl.gz       # Stream of native RawEvents in chronological received_at order
├── truth.jsonl.gz        # Sidecar ground-truth EventTruth records, joined 1:1 by seq
├── actors.jsonl.gz       # Simulated population metadata, demographics, and actor attributes
├── institutions.json     # Institutional participants (banks, schemes, acquirers, exchanges)
├── party_map.jsonl.gz    # (Optional) actor_id -> party_id resolution table
└── manifest.json         # Cryptographic checksums, parameters, and generation report
```

### Path Restrictions
Dataset names must match the regex `^[a-z0-9][a-z0-9_.-]{0,63}$`. Path traversal attempts (e.g. `../` or absolute paths) are strictly rejected.

---

## File Contents & Schemas

### 1. `events.jsonl.gz`
- Contains one line per transaction lifecycle event in strict `received_at` non-decreasing order.
- Each line is a JSON object serialized from `ripple.adapters.contract.RawEvent`:
  ```json
  {
    "event_id": "ev_8f3a1b7e2c9d4e5f601a",
    "network_id": "card",
    "payload": { ... },
    "payload_format": "JSON",
    "received_at": "2026-01-05T08:14:23Z",
    "source": "sim_engine"
  }
  ```
- **Strict Requirement (R3)**: `events.jsonl.gz` never contains any ground truth, scenario labels, mule indicators, or fraud markers.

### 2. `truth.jsonl.gz`
- Contains one line per event matching the line index and sequence ID in `events.jsonl.gz`.
- Schema:
  ```json
  {
    "seq": 0,
    "event_id": "ev_8f3a1b7e2c9d4e5f601a",
    "logical_txn_id": "card:auth_981245",
    "stage": "authorization",
    "network_id": "card",
    "event_time": "2026-01-05T08:14:20Z",
    "scenario_id": "card_testing",
    "pattern": "CARD_TESTING",
    "regime": "baseline",
    "is_fraud": true,
    "hard_negative": false,
    "lookalike_of": null,
    "sender_actor_id": "A000142",
    "receiver_actor_id": "A000012",
    "sender_role": "VICTIM",
    "receiver_role": "FIRST_HOP",
    "sender_institution_id": "I01",
    "receiver_institution_id": "I02",
    "label_available_at": "2026-01-07T12:00:00Z",
    "expected_error": false,
    "duplicate_of": null
  }
  ```

### 3. `actors.jsonl.gz`
- Contains one record per actor in the simulated world:
  - `actor_id` (e.g. `"A000001"`)
  - `kind` (`individual`, `merchant`, `business`, `exchange`, `psp`, `service`, `bank`)
  - `country` (ISO-3166 alpha-2)
  - `timezone` (IANA timezone name)
  - `institution_id`
  - `created_at` (ISO-8601 UTC)
  - `activity_multiplier`
  - `mcc` (if merchant)
  - `shared_phone`, `shared_email`

### 4. `institutions.json`
- An uncompressed JSON array of institution objects participating in the simulation:
  - `institution_id` (`"I01"`, `"I02"`, ...)
  - `name`
  - `country`
  - `bic`
  - `upi_handle`
  - `ifsc_prefix`
  - `issuer_id`
  - `acquirer_id`
  - `size_weight`

### 5. `manifest.json`
- Comprehensive dataset descriptor with cryptographic integrity hashes:
  ```json
  {
    "algorithm_version": "1",
    "generator_version": "0.1.0",
    "dataset_name": "small-42",
    "created_at": "2026-01-05T00:00:00Z",
    "config": { ... },
    "config_hash": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855",
    "calibration_name": "default",
    "calibration_hash": "a1b2c3d4...",
    "provenance_summary": {
      "assumption": 84,
      "published": 0
    },
    "counts": {
      "total_events": 14205,
      "by_network": {
        "card": 4120,
        "crypto": 1850,
        "swift": 940,
        "upi": 5210,
        "wallet": 2085
      },
      "fraud_events": 142,
      "hard_negative_events": 426
    },
    "truncated_count": 0,
    "resolved_warnings": [],
    "file_checksums": {
      "actors.jsonl.gz": "...",
      "events.jsonl.gz": "...",
      "institutions.json": "...",
      "truth.jsonl.gz": "..."
    },
    "dataset_checksum": "..."
  }
  ```

## Canonical Serialization & Compression Rules

1. **JSON Formatting**:
   - Keys are sorted (`sort_keys=True`).
   - Compact whitespace separators: `separators=(',', ':')`.
   - ASCII guaranteed: `ensure_ascii=True`.
   - Datetimes formatted as ISO-8601 with trailing `Z` (e.g. `2026-01-05T00:00:00Z`).
   - Decimals formatted as exact string values (never converted to IEEE 754 floats).

2. **Deterministic GZIP**:
   - All `.gz` archives are created with `mtime=0`.
   - This ensures identical content yields byte-identical compressed archives regardless of when or where the archive is produced.

3. **Atomic Writes**:
   - The dataset is written to a temporary staging folder (`.tmp_<name>_<pid>`).
   - On completion, files are hashed and the directory is atomically renamed to its final path.
   - Refuses to overwrite an existing directory unless `overwrite=True` is explicitly specified.
